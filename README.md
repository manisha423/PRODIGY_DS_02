PRODIGY_DS_02 – Data Cleaning and Exploratory Data Analysis

Task

Perform data cleaning and exploratory data analysis (EDA) on a dataset of choice. Explore the relationships between variables and identify patterns and trends in the data.

Dataset

For this task, the Titanic dataset was used.

The dataset contains information about passengers, including:

- Passenger class
- Gender
- Age
- Number of siblings/spouses
- Number of parents/children
- Fare
- Port of embarkation
- Survival status

Data Cleaning

The following data-cleaning steps were performed:

- Checked the dataset structure and information.
- Checked for missing values.
- Checked for duplicate records.
- Handled missing values in the "Age" column using the median.
- Verified the cleaned dataset.

Exploratory Data Analysis

The following analyses and visualizations were performed:

- Survival count
- Survival by gender
- Survival by passenger class
- Age distribution
- Fare vs. survival
- Correlation heatmap
- Survival percentage

Key Findings

- Survival differed between male and female passengers.
- Passenger class showed a relationship with survival.
- The age distribution of passengers was explored.
- Fare values showed differences between passengers who survived and those who did not.
- Numerical relationships were analyzed using a correlation heatmap.
